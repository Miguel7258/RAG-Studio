O RAG Studio coordena dois modelos de IA em equipa: um modelo compacto e rápido (SLM de 1B a 3B) analisa e reformula a tua pergunta para encontrar os trechos mais relevantes nos documentos; em seguida, o modelo principal gera uma resposta completa com citações fiáveis.

O que significam as quantizações?

As quantizações comprimem os números do modelo para poupar memória. Q4_K_M é o padrão recomendado (melhor equilíbrio entre velocidade, qualidade e tamanho). Q8_0 preserva fidelidade máxima a troco de mais VRAM. Q2/Q3 são ultraleves para sistemas com pouca memória.

Como Começar com o RAG Studio

Sem registos na nuvem, sem comandos complexos no terminal. Pronto a usar em poucos minutos.

01

1. Transferir o RAG Studio

Descarrega o instalador oficial (.exe) ou a versão portátil (.zip). Instalação limpa no Windows 10 ou 11, sem serviços de fundo invasivos.

Ver opções de download
02

2. Escolher um Modelo de IA

Utiliza o catálogo integrado no programa ou no site para obter um ficheiro .gguf compatível (como Qwen, Gemma ou Llama), ou coloca qualquer modelo que já tenhas na pasta.

03

3. Adicionar Documentos e Conversar

Arrasta os teus PDFs, manuais técnicos, relatórios ou notas. O RAG Studio divide o texto em blocos semânticos e responde às tuas perguntas com citações diretas das fontes.

Privacidade e isolamento total

Requisitos do Sistema & Informações Técnicas

MÍNIMO

• Windows 10 / 11 64-bit

• Processador x64 Quad-Core

• 8 GB de memória RAM

• 2 GB de espaço livre em disco

RECOMENDADO

• 16 GB+ de RAM do sistema

• GPU NVIDIA RTX (6GB+ VRAM CUDA) ou AMD Radeon recente

• Disco SSD NVMe para carregamento veloz de pesos

• Modelos quantizados em Q4_K_M
