PIPELINE COOPERATIVO

Arquitetura de Motor Dual-IA

O RAG Studio orquestra dois modelos de IA em simultâneo: a NPU/CPU executa um modelo ultra-rápido (SLM de 1B a 3B) para reformular a pesquisa e a GPU principal gera a resposta fundamentada com os documentos recuperados.

Etapa 1: SLM (NPU/CPU) ~30ms (Query Reformulation)
Etapa 2: Recuperação Vetorial ~15ms (Chunk Matching)
Etapa 3: LLM Principal (GPU) Streaming com Flash Attention
